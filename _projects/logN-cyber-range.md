### Cyber Range (Log(N) Pacific) – Vulnerability Management Labs
***Hands-on enterprise simulation using Tenable & Azure***
- Built and managed Windows and Linux virtual machines in Azure, intentionally introducing insecure configurations, outdated software, and weak credentials to simulate real-world vulnerability scenarios.
- Conducted authenticated and unauthenticated vulnerability scans using Tenable Vulnerability Management (Nessus) and analyzed differences in scan depth, duration, and findings.
- Performed full vulnerability management lifecycle activities: discovery, assessment, prioritization, reporting, remediation, and verification through rescanning.
- Executed manual and programmatic remediation on Windows and Linux systems, including disabling SMBv1, removing Telnet, fixing insecure SSH/root configurations, and updating vulnerable software.
- Applied DISA STIG compliance scans to Windows and Linux hosts and validated remediation against security baselines.
- Implemented agent-based vulnerability monitoring using Nessus Agents to simulate remote endpoints and mobile workforce scenarios.
- Practiced vulnerability recasting and risk acceptance, documenting business justification, POAM-style thinking, and compensating controls.
- Conducted network-wide discovery scans to identify unmanaged or rogue assets and classify systems for ongoing remediation cycles.
