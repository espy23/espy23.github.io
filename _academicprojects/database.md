### Course: Principles of Database Systems
#### Assignment: Relational Database and Application Development
***Overview: Designed and implemented a user-friendly interface resembling a real-world Point of Sale system used in a concert venue, incorporating features such as clocking in, sales lookup, employee tip information, and product information/prices.***
- Built a 3-tier application with HTML in the front end, PHP in the middle tier, and MySQL in the database layer.
- Modeled the application after the POS system used at a concert venue, enabling clock-in/out, sales lookups, tip information, and product details for users.
 - Developed manager-level functionality to view transactions, all sales, edit product and customer information, and generate detailed reports.
 - Created a variety of database components to meet project requirements, including views, procedures, functions, triggers, and reports with aggregation.
- Applied normalization techniques to ensure data integrity and reduce redundancy.
- Used prepared statements to prevent SQL injection, adhering to best practices in database security.
**Technical Skills: HTML, CSS, PHP, MySQL**
