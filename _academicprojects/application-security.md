### Course: Application Security
#### Assignment: Code Auditing and Analysis
***Overview: Carried out auditing and security enhancement of a gift card web application.***
- Conducted an in-depth code audit of a web application for facilitating gift card sales and usage to identify vulnerabilities and potential security risks.
- Applied code coverage analysis techniques and conducted fuzz testing, providing an extensive set of test cases to expose critical flaws in the program's functionality.
- Identified the root cause of each bug and fixed the code to mitigate each one.
- Strengthened the security of the web application by implementing database encryption for gift card data and using proper key management.

**Technical Skills: C, Git version control, Fuzz testing, Code coverage analysis, Debugging with gdb, Django, Docker, Secure coding practices**
